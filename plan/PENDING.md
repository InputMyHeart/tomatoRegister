# 当前待办

本文件是项目唯一的待办入口，只记录尚未完成、需要决策或明确暂缓的事项。当前实现事实与长期规则分别维护在 `README.md` 和 `docs/`；已完成记录由 Git 历史承担。

## 待产品决策

### 成员退出与 Owner 转移

- 待明确成员退出后历史记录的归属、可见性及头像/昵称展示。
- 待明确 Owner 是否可退出，以及账本如何转移或处置。
- 规则确定后同步补充数据约束、权限逻辑、迁移策略和测试。

### 邀请生命周期

- 待明确邀请有效期、撤销规则、重复领取及领取后失效规则。
- 规则确定后同步补充字段、索引、服务端校验、页面状态和测试。
